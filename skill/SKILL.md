# askme：远程确认（Claude Code / Codex 通用）

## 判断流程

先运行 `~/.cc-remote/bin/ccr status` 看远程确认开关（dingtalk-notify）：

- **远程确认=off**（用户在电脑前）：不要用本技能。Claude Code 用 AskUserQuestion 提问；Codex 直接文本提问。
- **远程确认=on**（用户可能不在电脑前）：**所有**需要用户决策的提问都改用 `ccr ask`，不要用 AskUserQuestion、不要只在终端提问后结束回合（用户看不到）。

## 远程确认开启时的用法

用 Bash 工具运行（**timeout 参数必须设 600000**）：

```bash
~/.cc-remote/bin/ccr ask "简洁描述要确认的问题" --options "1=选项一,2=选项二"
```

- **stdout = 用户的回复原文**（选项数字或自由文本），据此继续工作
- stdout 为 `TIMEOUT`：用户长时间未回复。不要重复发起询问，选择安全默认继续并在最终输出里说明，或停止并总结当前进度
- 选项设计：2~3 个互斥选项，其中应包含"停止/稍后"类出口；能合并的小决策合并成一次询问，减少打扰
- 若 `ccr ask` 以非 0 退出且 stderr 提示远程确认未开启，回退为常规提问

## 边界说明

- Claude Code 的权限审批弹窗由系统 hooks 自动发钉钉远程放行，无需本技能介入
- Codex 没有审批 hook，审批类弹窗只能回电脑处理；问询类决策本技能完全可用
- 不要把密钥、内部代码大段发进钉钉；命令/文件预览即可
